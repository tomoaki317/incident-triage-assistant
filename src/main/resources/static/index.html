合成データを使用してください。実顧客のログ・個人情報・実際の認証情報は入力しないでください。 AIへの送信・解析は行いません。最終判断は担当者が行い、緊急時は既存の障害対応手順を優先してください。

自動検出は完全ではありません。氏名・住所・電話番号・顧客ID・社内ホスト名なども確認・除去してください。
